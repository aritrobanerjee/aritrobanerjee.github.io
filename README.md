# Portfolio: Aritro Banerjee

Live URL: https://aritrobanerjee.github.io/

## Technology Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Typography**: Geist, Geist Mono, Inter
- **Deployment**: GitHub Pages via GitHub Actions

## Structure
- `src/data/profile.json` - Profile and career content data
- `src/components/Header.tsx` - Header with monochrome avatar and glowing LED
- `src/components/Experience.tsx` - Nested company timeline
- `src/components/Focus.tsx` - Competencies index
- `src/components/Education.tsx` - Academic degrees and examination honors
- `src/components/Connect.tsx` - Text-first contact links
- `src/components/CardDeckBackground.tsx` - Interactive 3D flipping card deck canvas

## Commands
- `npm run dev` - Start local Vite dev server
- `npm run build` - Build production bundle to `dist/`
